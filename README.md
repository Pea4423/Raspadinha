# 🎁 Raspadinha Miramour

Bem-vindo(a) ao repositório da **Raspadinha Miramour**, uma das fases do jogo interativo chamado **"Miramour"**, criado como uma experiência afetiva, divertida e personalizada para reacender o amor e a conexão entre duas pessoas especiais.

---

## 💖 O que é a Raspadinha?

A **Raspadinha Miramour** é uma atividade interativa e visual inspirada nas tradicionais raspadinhas de sorte. Ao clicar em três cartinhas premiadas (✨ Pijamas ✨), a jogadora desbloqueia:

- Uma **mensagem romântica**
- E botões para resgatar sua **Carta + Premiação personalizada** via WhatsApp

Tudo feito com humor, carinho e muito afeto.

---

## 🎮 Parte do jogo "Miramour"

O projeto **Miramour** é um jogo criado com diversas etapas criativas, como:

- 🔍 Jogo da Memória
- 🧠 Quiz 
- 💌 Cartas premiadas
- ✨ Raspadinha (essa aqui!)
- 🔠 Caça-palavras 

Cada fase foi pensada com uma proposta lúdica, romântica e interativa, misturando elementos digitais e sentimentais.

---

## 🛠️ Tecnologias utilizadas

- HTML5

- JavaScript (lógica da raspadinha e controle dos prêmios)
